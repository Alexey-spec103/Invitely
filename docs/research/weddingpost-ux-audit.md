# weddingpost.ru UX audit — full user journey (2026-08-18)

Purpose: walk weddingpost.ru's entire funnel as a non-technical bride would, document every screen's copy/mechanics/tone, then compare against Invitely and apply concrete fixes.

**Scope note (copyright):** this document records structural/textual/interaction observations only — no images, templates, or copyrighted assets were downloaded or copied. Any visual description is a paraphrase for engineering reference, not a reproduction.

**Status:** complete. Live-walked the full funnel (landing → gallery → template modal → real signup/email confirmation → constructor → all 6 cabinet sections → published site) with a real test account the user registered themselves (account creation/password entry is off-limits for me to perform). Fixes were prioritized by cost/value and applied directly to the codebase; see §12 for what shipped and §13 for what's intentionally left for later.

---

## 2. Style gallery

Reached via the hero CTA — lands at `/cabinet/style/variant/?style=262#...`. Note this URL is already inside `/cabinet/` (the authenticated app's URL space) even though no login has happened yet — the gallery is served from the same route tree as the real editor, just gated on write actions, not read access.

**Layout**: this is the full app shell, not a marketing page — same dark maroon left icon rail already visible in the pre-login state (Стиль / Сайт / Бумажные / Гости / Приглашения / Банкет, six icons, "Стиль" active/highlighted), confirming the left-nav is a persistent app-wide chrome element the user sees from the very first design-picking moment, not something introduced later after signup. Top bar: logo, "Ru" language switcher, "Войти" (Log in) link, "Зарегистрироваться" (Register) outline-pill button — both present and clickable pre-signup, so a returning user can skip the gallery entirely.

## 3. Template card modal (Invitations / Banquet tabs)

Clicking a card's image (not the heart) opens a **full-viewport modal** (~1000px wide, not a small popup) with two pill tabs top-left, each icon baked directly into the tab label rather than a separate decorative icon: "🎁 Приглашения" (active by default) / "🥂 Банкет".

**Приглашения tab**: left ~55% of the modal shows a fanned, overlapping stack of paper-card mockups tilted at different angles (invitation card on top, a schedule/"Программа" card and a dress-code "...code" card peeking out from behind/below it) — same fanned-stack visual language as the landing page's hero composite photo, but here rendered as live UI elements, not a photo.
