# ЧАСТЬ I. ЭТАЛОН — кабинет weddingpost.ru

## 0. Карта кабинета и маршрут пользователя

Шесть разделов, расположенных в порядке подготовки свадьбы, а не в порядке «разделов админки»:

```
Стиль → Сайт → Бумажные → Гости → Приглашения → Банкет
```

URL-карта:

| Раздел | URL |
|---|---|
| Стиль (каталог) | `/cabinet/style/variant/?style=262` |
| Конструктор сайта | `/cabinet/constructor/electro/` |
| Конструктор бумажных | `/cabinet/constructor/paper/` |
| Гости | `/cabinet/` |
| Приглашения (результат) | `/cabinet/finish/invite/` |
| Банкет | `/cabinet/finish/banket/` |

**Два визуальных режима кабинета:**

- **Светлый** (персиково-серый фон, персиковый рейл, белая шапка) — управляющие экраны: Стиль, Гости, Приглашения, Банкет.
- **Тёмный** (тёмно-сине-фиолетовый фон, тёмный рейл) — рабочие экраны конструктора: Сайт, Бумажные.

Смена среды сообщает смену задачи: «сейчас ты выбираешь и управляешь» против «сейчас ты творишь».

**Сквозная нижняя навигация.** Внизу каждого экрана — путь назад и вперёд по воронке:

| Экран | Слева | Справа |
|---|---|---|
| Конструктор сайта | `← Назад к стилям` | `Бумажные →` |
| Конструктор бумажных | `← Назад к стилям` | `Гости →` |
| Гости | `← Конструктор` | `Получить →` |
| Приглашения | `← Конструктор` | `Банкет →` |
| Банкет | `← Приглашения` | — |

## 1. Вход в кабинет

Точка входа — кнопка «СДЕЛАТЬ СВОИ ПРИГЛАСИТЕЛЬНЫЕ» с лендинга. Пользователь попадает сразу на `/cabinet/style/variant/`, то есть **первый экран кабинета = выбор стиля**.

Ключевое: **ни одного вопроса до первого «вау»**. Нет дашборда, нет списка проектов, нет онбординг-формы «как зовут / когда свадьба». Сначала красота, потом данные.

Шапка кабинета минимальна: логотип слева, почта пользователя справа с дропдауном и круглым аватаром-иллюстрацией. Никакой навигации по лендингу, никаких кнопок публикации. Кабинет визуально изолирован от сайта.

## 2. Каталог стилей внутри кабинета

### 2.1. Раскладка — четыре колонки

Слева направо:

1. **Иконочный рейл** (~85 px), на всю высоту.
2. **Панель категорий** (~340 px) с собственным скроллбаром.
3. **Кнопка-схлопывалка `«`** — круглая, на границе, сворачивает панель категорий.
4. **Область контента** — заголовок + сетка карточек.

Фон — бледно-персиковый. Не белый и не тёмный.

### 2.2. Иконочный рейл

`Стиль` · `Сайт` · `Бумажные` · `Гости` · `Приглашения` · `Банкет`

Каждый пункт — **иллюстрированная цветная иконка** + подпись под ней. Активный раздел подсвечен **оранжевой заливкой на всю ячейку**.

### 2.3. Панель категорий — двухуровневая

**Верхний блок (входы, а не категории):**

| Пункт | Особенность |
|---|---|
| Популярные | активен по умолчанию, розовая pill-заливка, иконка искр |
| Новые | бейдж «NEW» |
| Осень 2026 / Зима 2026 / Весна 2026 / Лето 2026 | сезонные коллекции **с годом**, у каждой своя иконка (лист, снежинка, росток, пион) |
| Любимые | счётчик, растёт по мере лайков (был 7 → стал 8) |
| ИИ подборка от феи | иконка феи |

**Разделительная линия.**

**Нижний блок — визуальные категории со счётчиками:**

Минимализм **146** · Лайн-арт **23** · Типографика **29** · Цветочный минимализм **45** · Фото-приглашение **43** · Белые цветы **29** · Қазақша шақырулар **67** · Агатовый **15** · Мраморный **19** · Прованс **20** · Романтический **88** · Пионы **23** · Бохо **17** · Анималистика **33** … и дальше.

Три важных свойства:

- **У каждой категории своя нарисованная иконка** — два кольца, сердце-контур, буква T, цветок, рамка с фото, лилия, флаг Казахстана, срез агата, разводы мрамора, лаванда, роза, пион, ветка, птица. Не универсальные глифы, а знак под каждую категорию.

- **Категории описывают технику и мотив, а не настроение:** «Агатовый», «Мраморный», «Лайн-арт», «Анималистика».

## 3. Конструктор «Сайт» (`/cabinet/constructor/electro/`)

### 3.1. Общая раскладка

Фон — **тёмный сине-фиолетовый**. Резкий контраст с персиковым каталогом: как только начинается работа, интерфейс уходит в тёмное, чтобы холст был единственным светлым пятном.

Три вертикальные зоны: левая (рейл + модули) → центр (холст) → правая (панель настроек).

### 3.2. Верхняя панель

- Логотип слева.
- По центру — **undo / redo**, крупные круглые стрелки.
- Справа: `✏ Активировать сайт` (светлая pill с розовой обводкой) + `💾 Сохранить` (оранжевая градиентная pill) + почта с аватаром.

Две кнопки разного веса: сохранить — приоритетное действие, активировать — платное, поэтому визуально спокойнее.

### 3.3. Колонка «Модули»

Плавающая колонка правее рейла: вертикальный столбик из 10 иконок. У части иконок слева — **маленькая оранжевая точка** = модуль включён. Внизу — крупная круглая оранжевая кнопка **«+»** со свечением.

**При клике колонка разворачивается в панель со списком и тумблерами:**

| Модуль | Состояние на скрине |
|---|---|
| 🔗 Меню навигации | выкл |
| 📅 В календарь | выкл |
| ⏳ Обратный отсчет | вкл |
| ▭ Палитра | вкл |
| 👤 Подтверждение | вкл |
| 💬 Сообщение | вкл |
| $ Деньги в подарок | вкл |
| ☑ Опрос гостей | вкл |
| ▤ Расписание | выкл |
| 🗺 Карта | вкл |

Внизу — широкая оранжевая кнопка **«+ Добавить элемент»**.

Принцип: **свёрнутое состояние = быстрый статус** (какие модули включены, видно точками), **развёрнутое = управление**. Иконки в свёрнутом виде работают как якоря на секции страницы.

### 3.4. Центр: холст

- Приглашение в **рамке планшета/телефона** со скруглёнными углами, боковыми кнопками громкости и собственным скроллбаром справа.
- Внутри — реальный сайт, прокручивается целиком: коллаж из фото → имена рукописью → «А + D = ♡» → заголовок капсом → дата → таймер → гирлянда-флажки → «Дорогой Гость!» → текст → «МЕНЮ» → палитра дресс-кода → кнопка «Подтвердить» → поле сообщения → чекбокс «денежный подарок» с суммой → опрос с радиокнопками → Яндекс.Карта → футер с логотипом.
- По бокам холста — **вертикальные «ушки»-хендлы**, бледные полоски слева и справа: ресайз/перетаскивание блока.
- При выделении блока появляется **бирюзовая рамка** и два квадратных контрола слева: цветной свотч (цвет фона блока) и тёмный квадрат с шестерёнкой (настройки блока).

### 3.5. Правая панель — сверху вниз

**1) Переключатель устройства** — pill с двумя иконками: телефон (активен, персиковая заливка) / планшет.

**2) Ряд из 5 иконок-инструментов** с цветными точками-индикаторами: экспорт/поделиться, обновить (зелёная точка), линейка/направляющие (красная точка), «?» помощь, база данных (зелёная точка). Точки показывают, какие режимы активны.

**3) Слоты стилей.** Карточка с миниатюрой текущего стиля, языком `ru ▾`, номером **#1291**, названием категории «Необычные», кнопкой **«Заменить»** и иконкой **истории версий** (⟲). Справа — **пустой слот с «+»**: можно держать несколько вариантов дизайна и переключаться между ними.

**4) ИИ-Дизайнер фея Виви ★100.** Фиолетовая панель с аватаром-иллюстрацией. Сообщение: «Все варианты я буду собирать тут — так ты сможешь переключаться между ними.» Ниже — **цветовые пресеты как пилюли, каждая окрашена в свою гамму**: Исходный стиль, Мятный сад, Вишня в саду, Мёд и хвоя, Лазурь, Морозный лес, Капучино, Аметист, Кремовый лён, Янтарный… со стрелкой-каруселью вправо. Ниже: `Открыть диалог` · `Покажи идеи ✨` · поле «Напиши сообщение…» · круглая кнопка отправки с волшебной палочкой.

Модель проста и безрисковая: **ИИ не генерирует с нуля, а перекрашивает текущий шаблон**, гаммы названы вкусно, результаты складываются в слоты.

**5) Три карточки быстрых настроек:** «Стартовый экран», «Музыка», «Превью». У каждой — зелёный бейдж **«✅ Настроено»**, превью-картинка (обложка; голуби «Письмо небесам» с плеером; превью ссылки как в мессенджере — «Приглашение на свадьбу — Ааа &… / Жених и Невеста приглашают вас на…») и персиковая кнопка **«Изменить»**.

Карточка «Превью» — это **как ссылка будет выглядеть при отправке в мессенджер**. Отдельная продуманная деталь.

**6) Баннер-напоминание.** Полоса с оранжевой чертой слева, иконкой ⚠ и текстом: «Заполните недостающую информацию о свадьбе, чтобы полностью сформировать текст» + персиковая кнопка **«Данные свадьбы»**.

**7) Поля данных прямо в панели:** `Место` (плейсхолдер «Название ЗАГСа, ресторана…»), `Город`, `Адрес` — подчёркнутые инпуты без рамок.

**8) Секции настроек с радио-маркерами (○):**

- **«Графический элемент»** — два круглых **D-pad контроллера**: слева крестовина перемещения (4 стрелки + центр), справа поворот ↺ ↻ и масштаб + −. Ниже — ряд квадратных слотов с вариантами графики и слот «+» пунктиром для загрузки своей.
- **«Фон главного блока»** / **«Фон блока приглашения»** — круглые дропдауны-пилюли.
- **«Поля блока приглашения»** — два дропдауна + тумблер **«только десктоп»**.
- **«Фон опроса»** — при раскрытии: **слайдер «Прозрачность»** + сетка из ~24 свотчей: сплошные цвета, градиенты, **текстуры дерева, бетона, мрамора, льна**, у двух последних шестерёнка для тонкой настройки. Внизу ссылка **«Настроить мою палитру»**.
- **«Футер»** — свой дропдаун фона.

**9) «Редактируемые блоки» со счётчиком — 38.** Раскрывающийся список **всех текстовых и графических элементов страницы**, каждый строкой с иконкой типа:

| Иконка | Тип | Примеры строк |
|---|---|---|
| `A` | текст | «МЫ ВЫРОСЛИ, И ТЕПЕРЬ НАМ МОЖНО!», «Ааа», «Ddd», «01 ЯНВАРЯ 2027», «A + D = ♡», «10:00», «Там, где посеяна любовь, растёт радость», «МЕНЮ», «ПОЖЕЛАНИЯ ПО ПОДАРКАМ», «ПРИМЕЧАНИЕ», «ПОДТВЕРЖДЕНИЕ», «ФОТО», «Ждем Вас на нашей свадьбе!» |
| `🖼` | изображение | строка с превью-миниатюрой |
| `⊞` | «Групповой элемент» | контейнер |
| `🖊` | «Автоматическое поле» | подставляется из данных свадьбы |

Это **дерево слоёв, но на языке невесты**. Не «Layer 12», а сам текст блока. Для страницы из 38 элементов — единственный способ ничего не потерять.

### 3.6. Онбординг конструктора — карусель из 6 карточек

Всплывающие карточки в левом нижнем углу, с точечным индикатором, кнопками «Пропустить» / «Назад» / «Далее», на последней — «Понятно». У каждой бейдж **NEW** и своя иллюстрация:

1. **«Интерактивное редактирование»** — арт с космонавтами-молодожёнами, показан режим выделения с маркерами и подписью масштаба «9.3%». «Создавайте легко приглашения, которые стоят десятки тысяч рублей. Тут комьюнити свадебных дизайнеров» + **ссылка на Telegram-канал**.
2. **«Те самые трендовые виды расписания»** — три варианта таймлайна свадебного дня рядом.
3. **«Красивые эффекты и живая анимация»** — «Andrey AND Marta» на золотом боке, сверху **реальная плавающая тулбар-панель форматирования**: пауза, эффект, `zoom↓`, `0.5s`, выравнивание, `Cormorant`, свотч цвета, `80pt`, +/−, перемещение, эмодзи.
4. **«Дизайн-помощник в редакторе»** — фото пары с направляющими и кнопкой «Исправить», иконка линейки.
5. **«Фоторедактор и удаление фона»** — фото с шахматной прозрачностью и панелью слайдеров. «чтобы фотографии стали красивой частью дизайна, а не просто вставкой в макет».
6. **«Удобный сбор денежного подарка»** — прозрачная урна с купюрами и **логотипы ЮMoney, Т-Банк, Сбер, ВТБ**.

Онбординг **не объясняет базовое** («вот кнопка сохранить») — он **продаёт самые сильные фичи** и создаёт ощущение, что продукт живой.

Плюс постоянные элементы: бейдж **«NEW V10»** с кружком «i» внизу рейла и **круглый чат-виджет** в левом нижнем углу.

## 4. Конструктор «Бумажные» (`/cabinet/constructor/paper/`)

### 4.1. Что меняется относительно «Сайта»

Раскладка та же, содержимое всех трёх колонок другое:

| | Сайт (electro) | Бумажные (paper) |
|---|---|---|
| Кнопка справа вверху | `✏ Активировать сайт` | **`🎁 Получить`** |
| Верх холста | ничего | **`↺ перевернуть`** + зум `−` / `+` |
| Холст | рамка планшета со скроллом | **лист бумаги** с тенью, без рамки устройства |
| Навигация по холсту | скролл внутри устройства | **стрелки `‹` `›` по бокам** — листание между материалами |
| Правая панель, верх | переключатель телефон/планшет | **три круглые кнопки добавления** |
| Внизу справа | `Бумажные →` | `Гости →` |

### 4.2. Колонка модулей — сгруппирована по разделам

Вместо плоского списка — **три подписанные группы**:

**Приглашение**

## 8. Сквозные системы weddingpost — 30 принципов

1. **Вход = выбор стиля.** Никаких форм до первого «вау».
2. **Персиковый каталог → тёмный конструктор.** Смена режима обозначена сменой всей среды.
3. **Рейл из 6 разделов = порядок подготовки свадьбы**, а не разделы админки.
4. **Категории с индивидуальными иконками и растущими неровными счётчиками.**
5. **Карточка стиля — один клик до «Настроить»**, с сердцем-избранным и рамкой при наведении.
6. **Модули: свёрнуто = статус с точками, развёрнуто = тумблеры.**
7. **Слоты вариантов дизайна + история версий.**
8. **ИИ как перекрасчик текущего шаблона** с вкусными названиями гамм, а не генератор с нуля.
9. **«Редактируемые блоки» — дерево слоёв на человеческом языке, со счётчиком.**
10. **Фоны как полноценная библиотека:** цвета + градиенты + текстуры + прозрачность + своя палитра.
11. **Карточка «Превью» = вид ссылки в мессенджере.**
12. **Данные свадьбы вводятся прямо в панели**, с баннером-напоминанием, и подставляются в «Автоматические поля».
13. **Внизу всегда путь назад и вперёд** — воронка зашита в навигацию.
14. **Онбординг продаёт фичи**, а не объясняет кнопки, и уводит в Telegram-комьюнити.
15. **Два визуальных режима кабинета** — светлое управление / тёмное творчество.
16. **Один стиль → восемь носителей** из одной колонки модулей.
17. **Оборот приглашения = функциональный носитель** с персональным QR и коротким доменом для ручного набора.
18. **Модель данных: приглашение ≠ гость.** Одно приглашение — несколько гостей, один QR, один статус. Платная опция `+1`.
19. **Автозаполнение гостей** предложено прямо в форме ручного ввода.
20. **Живой менеджер с фотографией** и контактами в четырёх каналах, на двух экранах.
21. **Сквозной блок «Стиль / Информация (45%) / Баланс»** на всех финишных экранах.
22. **Модель баланса**, а не разовой оплаты. Платёжные бейджи PCI DSS у кнопки пополнения.
23. **Watermark «НЕ ОПЛАЧЕНО»** поверх готового макета.
24. **`0/∞`** как способ сказать «лимитов нет» цифрой.

## Что у тебя уже сделано правильно

Чтобы не потерялось в списке проблем:

- Каталог стилей — **первый экран кабинета**, без форм до него.
- Правая панель карточки стиля теперь **содержательная** (монограммы, имена, даты, орнаменты) — раньше была пустой.
- **LAYOUT-таксономия по технике** с неровными счётчиками — сделано ровно как надо.
- **Единый формат даты** во всех карточках.
- Баннер **автозаполнения гостей по ссылке** с кнопкой `Copy site link`.
- **Три статусные карточки** Wedding style / Wedding details / Your plan — скопированы верно.
- `Flip to back` и стрелки листания носителей.
- **QR-персонализация** с автоматическим матчингом RSVP.
- **Экспорт печатного списка гостей** — этого у конкурента нет.
- **Danger zone** оформлена грамотно.
- **Мультипроектность** — селектор событий в шапке, чего у weddingpost нет вовсе.
- **Прогресс-бар заполненности** данных события.

## Итог одной фразой

У weddingpost кабинет устроен как **мастерская**: выбрал стиль → зашёл в тёмный конструктор → раскатал один дизайн на восемь носителей → собрал гостей → забрал результат → рассадил банкет, и на каждом шаге интерфейс показывает, что получится, и продаёт следующий шаг.

У Invitely кабинет устроен как **панель настроек**: разделы админки, формы, порядок секций стрелками, кнопки скачивания. Каркас правильный и местами уже повторяет эталон, но не хватает главного — **визуального конструктора вместо формы настроек, печатной ветки как полноценного раздела и момента «вот твой результат, забери его»**.
